# DocDrift Demonstration

This example demonstrates deterministic detection of an outdated CLI flag.

## Files

- `input.diff` — A unified diff renaming `--deadline` to `--timeout-limit`.
- `actual_output.txt` — Actual output generated by `docdrift.detector.detect_drift`.

## Reproduce

From the repository root, run:

    python3 -c 'from pathlib import Path; from pprint import pprint; from docdrift.detector import detect_drift; d=Path("examples/docdrift_demo/input.diff").read_text(); f=detect_drift(d, Path("examples/sample_repo")); print("Findings count:", len(f)); pprint(f, sort_dicts=False)'

The detector reports the outdated `--deadline` reference in the sample documentation and identifies `--timeout-limit` as its replacement.
